# Fonts for generated images

Raw WOFF files read by `app/icon.tsx`, `app/apple-icon.tsx` and `app/opengraph-image.tsx`
(satori, used by `next/og`, cannot read woff2).

- `cormorant-garamond-latin-500-italic.woff`: Cormorant Garamond 500 italic, latin subset
- `hanken-grotesk-latin-500-normal.woff`: Hanken Grotesk 500, latin subset

Source: `@fontsource/cormorant-garamond@5.3.0` and `@fontsource/hanken-grotesk@5.3.0` (npm).
